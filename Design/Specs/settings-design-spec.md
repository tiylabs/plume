# Settings 窗口设计规范

适用范围：`Sources/Plume/Settings/` 下全部六个 tab（通用、存储、外观、快捷键、Agent、关于）。Agent 页内容较多，与快捷键页一样在窗口内滚动。令牌的**唯一来源**是 `SettingsForm.swift`，本文只解释它们；改数值请改代码，再同步这里。

## 1. 结构：页 → 卡片 → 行

```
┌ 窗口 540pt（固定，所有 tab 同宽，否则切 tab 时窗口会跳）
│  页边距 24 ┌ 分组标题（可选）11pt semibold，次级色
│            ├ 卡片 492pt  圆角 10  0.5pt 描边  白 / 深色下白 7%
│            │   行  [标题 13pt ········ 控件]   最小高 40，上下内边距 8
│            │   ───── 分隔线（两端各内缩 14）
│            │   行  [标题 / 说明 11pt ·· 控件]
│            └ 脚注（可选）11pt，次级色，紧贴上方卡片
│  卡片间距 16 ｜ 标题与卡片间距 6
```

| 令牌 | 值 | 用途 |
|---|---|---|
| `contentWidth` | 540 | 窗口内容宽度 |
| `pageInset` / `pageTop` / `pageBottom` | 24 / 20 / 28 | 页边距 |
| `cardWidth` | 492 | 卡片、标题、脚注、底部按钮统一宽度 |
| `cardGap` / `captionGap` | 16 / 6 | 卡片间距 / 标题到卡片 |
| `cardRadius` | 10 | 卡片圆角 |
| `rowInset` | 14 | 行左右内边距，也是分隔线、标题、脚注的缩进 |
| `rowVerticalPadding` / `rowMinHeight` | 8 / 40 | 行高 |
| `rowSpacing` | 12 | 行内文字与控件最小间距 |
| `explanationWidth` | 280 | 行说明的折行宽度 |
| `popUpMinWidth` | 150 | 所有下拉最小宽度，保证右缘整齐 |

## 2. 行的规则

1. **左文字右控件，控件右缘永远贴 `rowInset`**。整个窗口的控件因此落在同一条竖线上。
2. 标题一行；需要解释时放在**标题正下方**的说明里（11pt、次级色），不另起一行。
3. 一行只放一个控件。多个选项是同一设置的取值 → 用下拉；是独立开关 → 各自一行。
4. 标题与控件**垂直居中**；行高由两者中较高的决定，不得被卡片撑高。
5. 没有说明的行不预留说明的高度（隐藏的视图不占位）。

## 3. 控件选型

| 场景 | 控件 | 备注 |
|---|---|---|
| 开 / 关 | `NSSwitch`（小号） | 取代复选框 |
| 互斥的 2–3 个取值 | 下拉 | 取代单选组；不可用项置灰 |
| 3 个以内、需要一眼比较 | 分段控件 | 仅「外观」一行 |
| 固定色板 | 圆点按钮 | 选中为同色外环；强调色只用于交互态 |
| 打开系统面板 / 文件夹 | 圆角按钮 | 无省略号时即刻生效，有省略号表示会再询问 |
| 只读值 | 次级色文字 | 如「格式：Markdown (.md)」 |
| 录制快捷键 | 104×22 录入框 | 所有录入框同宽 |

## 4. 分组规则

- 同一张卡片里的行必须属于同一主题；换主题就换卡片。
- 卡片超过 5 行考虑拆分；超过 2 张卡片并且主题不同时，每张加分组标题（外观、快捷键页已用）。
- General 页的顺序固定：语言 → 唤出与收起 → 启动与图标 → 更新与排序。语言放最前，因为窗口是看不懂的语言时最先要找到它。

## 5. 文字

- 标题 13pt 系统字体、主色；说明 / 脚注 11pt、次级色；分组标题 11pt semibold、次级色。
- 不使用冒号后缀（`form.labelSuffix` 保留为兼容键，已不在窗口里使用）。
- 不使用固定灰色，一律走系统语义色，自动适配深色、增强对比度。

## 6. 深浅色

- 卡片底色在 `updateLayer` 里按当前外观解析：浅色纯白，深色为白色 7% 透明度叠在窗口底色上。
- 描边用 `separatorColor`，0.5pt。

## 7. 新增设置项的检查表

1. 属于哪张卡片？没有合适的卡片就新开一张，不要塞进不相关的卡片。
2. 控件按第 3 节选型，不新增控件样式。
3. 不手写任何边距、宽度、字体——全部走 `SettingsForm` / `SettingsRow`。
4. 文案同时加进 `Locales/en` 与 `Locales/zh-Hans`。
5. 截图检查：右缘对齐、行高 ≥ 40、浅色与深色都看一遍。
