# Writing preferences

Your agent reads this file before writing a note in Plume. Edit it freely — it is yours. Delete a
line you disagree with; delete the file if you want no preferences at all.

- Start every note with a short `# Title` that says what the note is about.
- Lead with the conclusion or decision, then the reasoning.
- Prefer short paragraphs and bullet lists over long prose.
- Write open items as tasks: `- [ ] what needs doing`.
- Keep my wording when editing an existing note; change only what I asked for.
- Do not add a date, a source line or a summary of our conversation unless I ask.
